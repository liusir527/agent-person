# 记忆系统分层设计方案（纯索引版）

> **版本**: v1.0.0
> **日期**: 2026-09-07
> **设计目标**: 摒弃 DB 依赖，用 index.md 纯文本索引实现分层流转机制

---

## 一、设计理念

### 1.1 核心思想

借鉴图书馆索引卡片的思想：
- **索引文件（index.md）** = 索引卡片目录，可全局 grep 搜索
- **经验文件（*.md）** = 实际藏书，存放完整内容
- **搜索方式** = 直接 grep 文本，准确可控

### 1.2 为什么摒弃 SQLite

| SQLite/FTS5 方案问题 | 纯索引方案优势 |
|---------------------|---------------|
| 依赖 sqlite3 + fts5 | 仅文件系统 |
| jieba 分词不完美 | 直接文本匹配 |
| 索引可能损坏 | index.md 可 Git 版本管理 |
| 跨环境需重建 | clone 即用 |
| 多语言环境兼容问题 | 纯文本无兼容问题 |

## 四、分层流转规则

### 4.1 晋升规则（稀疏 → 精炼）

**触发条件**：
- `hit_count >= 3`
- `reuse_success == true`

**动作**：
1. 移动文件：`sparse/` → `refined/`
2. 更新文件内 Frontmatter：`tier: refined`, `promoted_at: <时间>`
3. 从 `sparse/索引.md` 删除该行，添加到 `refined/索引.md`

### 4.2 退化规则（稀疏 → 过期）

**触发条件**：
- `last_hit_at` 距今超过 `decay_threshold_days`（默认30天）
- 未达到晋升标准

**动作**：
1. 移动文件：`sparse/` → `expired/`
2. 更新 Frontmatter：`tier: expired`, `expired_at: <时间>`
3. 从 `sparse/索引.md` 删除，添加到 `expired/索引.md`

### 4.3 恢复规则（过期 → 稀疏）

**触发条件**：
- 过期经验被再次命中且确认有用

**动作**：
1. 移动文件：`expired/` → `sparse/`
2. 重置 `last_hit_at`
3. 更新对应索引文件

### 5.1 搜索流程

```

│ 1. grep 搜索三层索引.md                    │
│    grep "关键词" sparse/索引.md refined/索引.md │

    │
    ▼
```

## 六、命中追踪

### 6.1 记录命中

当经验被命中时：
1. `hit_count + 1`
2. `last_hit_at = now`
3. 如果用户确认 `reuse_success`：
   - 设置 `reuse_success = true`
   - 检查晋升条件（hit_count >= 3 && reuse_success == true）

```python
def record_hit(exp_id: str, memory_root: Path, reuse_verdict: bool = None):
    """记录一次命中"""
    # 1. 找到经验文件（遍历三层）
    exp_file = find_experience_file(exp_id, memory_root)
    if not exp_file:
        return
    
    # 2. 更新 Frontmatter
    meta, body = parse_frontmatter(exp_file)
    meta['hit_count'] = meta.get('hit_count', 0) + 1
    meta['last_hit_at'] = datetime.now(timezone.utc).isoformat()
    if reuse_verdict is not None:
        meta['reuse_success'] = reuse_verdict
    
    # 3. 写回文件
    write_frontmatter(exp_file, meta, body)
    
    # 4. 更新对应索引.md
    update_index_row(exp_file.parent / '索引.md', exp_id, meta)
    
    # 5. 检查晋升
    if meta['tier'] == 'sparse' and meta['hit_count'] >= 3 and meta['reuse_success']:
        promote_to_refined(exp_id, memory_root)
```

### 6.2 更新索引行

索引文件中的一行需要包含 `hit_count` 和 `last_hit_at`，命中后更新这些值：

```python
def update_index_row(index_file: Path, exp_id: str, meta: dict):
    """更新索引文件中对应经验的行"""
    content = index_file.read_text(encoding='utf-8')
    
    # 找到以 exp_id 开头或包含该文件名的行
    lines = content.splitlines()
    for i, line in enumerate(lines):
        if exp_id in line or meta.get('title', '') in line:
            # 重建该行（保持格式）
            lines[i] = rebuild_index_line(meta)
            break
    
    index_file.write_text('\n'.join(lines), encoding='utf-8')
```

## 七、定时检查脚本

```python
#!/usr/bin/env python3
"""
tier_manager.py - 分层流转管理器
检查并执行稀疏 → 精炼、稀疏 → 过期的流转
"""

import re
from datetime import datetime, timezone, timedelta
from pathlib import Path

MEMORY_ROOT = Path(__file__).parent.parent
DEFAULT_DECAY_DAYS = 30

def now_iso():
    return datetime.now(timezone.utc).isoformat()

def parse_frontmatter(content: str) -> tuple[dict, str]:
    """解析 Frontmatter，返回 (meta dict, body)"""
    if not content.startswith('---'):
        return {}, content
    parts = content[3:].split('---', 1)
    if len(parts) < 2:
        return {}, content
    import yaml
    meta = yaml.safe_load(parts[1]) or {}
    body = parts[1].split('---', 1)[-1] if '---' in parts[1] else ''
    return meta, body

def write_frontmatter(file_path: Path, meta: dict, body: str):
    """写回 Frontmatter"""
    import yaml
    fm = yaml.dump(meta, allow_unicode=True, sort_keys=False)
    content = f"---\n{fm}---\n{body}"
    file_path.write_text(content, encoding='utf-8')

def check_tier_transitions():
    """检查并执行层级流转"""
    now = datetime.now(timezone.utc)
    experiences_dir = MEMORY_ROOT / 'knowledge' / 'experiences'
    
    for tier_dir in [experiences_dir / 'sparse', experiences_dir / 'refined']:
        if not tier_dir.exists():
            continue
        
        for md_file in tier_dir.glob('*.md'):
            if md_file.name == '索引.md':
                continue
            
            content = md_file.read_text(encoding='utf-8')
            meta, body = parse_frontmatter(content)
            
            tier = meta.get('tier', 'sparse')
            hit_count = meta.get('hit_count', 0)
            last_hit = meta.get('last_hit_at')
            reuse_success = meta.get('reuse_success')
            threshold = meta.get('decay_threshold_days', DEFAULT_DECAY_DAYS)
            
            if tier == 'sparse':
                # 检查晋升
                if hit_count >= 3 and reuse_success:
                    promote_to_refined(md_file, meta, body)
                    continue
                
                # 检查退化
                if last_hit:
                    last_hit_dt = datetime.fromisoformat(last_hit.replace('Z', '+00:00'))
                    if (now - last_hit_dt).days > threshold:
                        demote_to_expired(md_file, meta, body)

def promote_to_refined(file_path: Path, meta: dict, body: str):
    """晋升：sparse → refined"""
    experiences_dir = MEMORY_ROOT / 'knowledge' / 'experiences'
    
    # 移动文件
    new_path = experiences_dir / 'refined' / file_path.name
    file_path.rename(new_path)
    
    # 更新 meta
    meta['tier'] = 'refined'
    meta['promoted_at'] = now_iso()
    write_frontmatter(new_path, meta, body)
    
    # 更新索引文件
    remove_from_index(experiences_dir / 'sparse' / '索引.md', file_path.name)
    add_to_index(experiences_dir / 'refined' / '索引.md', meta)
    
    print(f"[晋升] {file_path.name} → refined/")

def demote_to_expired(file_path: Path, meta: dict, body: str):
    """退化：sparse → expired"""
    experiences_dir = MEMORY_ROOT / 'knowledge' / 'experiences'
    
    # 移动文件
    new_path = experiences_dir / 'expired' / file_path.name
    file_path.rename(new_path)
    
    # 更新 meta
    meta['tier'] = 'expired'
    meta['expired_at'] = now_iso()
    write_frontmatter(new_path, meta, body)
    
    # 更新索引文件
    remove_from_index(experiences_dir / 'sparse' / '索引.md', file_path.name)
    add_to_index(experiences_dir / 'expired' / '索引.md', meta)
    
    print(f"[退化] {file_path.name} → expired/")

def remove_from_index(index_file: Path, filename: str):
    """从索引中移除一行"""
    if not index_file.exists():
        return
    content = index_file.read_text(encoding='utf-8')
    lines = [l for l in content.splitlines() if filename not in l]
    index_file.write_text('\n'.join(lines), encoding='utf-8')

def add_to_index(index_file: Path, meta: dict):
    """添加一行到索引"""
    if not index_file.exists():
        return
    content = index_file.read_text(encoding='utf-8')
    new_line = build_index_line(meta)
    # 插入到表格末尾（找到最后一个 | 后换行）
    content += '\n' + new_line
    index_file.write_text(content, encoding='utf-8')

def build_index_line(meta: dict) -> str:
    """构建索引行"""
    date = meta.get('created_at', '')[:10] if meta.get('created_at') else ''
    title = meta.get('title', meta.get('id', ''))
    filename = f"{title}-{meta.get('created_at', '')[:10].replace('-', '')}.md"
    summary = meta.get('summary', meta.get('title', ''))
    hit_count = meta.get('hit_count', 0)
    last_hit = meta.get('last_hit_at', '')[:10] if meta.get('last_hit_at') else ''
    reuse = str(meta.get('reuse_success', '')).lower()
    link = f"[{filename}]({filename})"
    return f"| {date} | {link} | {summary} | {hit_count} | {last_hit} | {reuse} |"

if __name__ == '__main__':
    check_tier_transitions()
```

## 八、搜索工具封装

```python
#!/usr/bin/env python3
"""
search.py - 纯文本索引搜索
直接 grep 索引文件，按 tier + hit_count 排序返回
"""

import re
import sys
from pathlib import Path
from datetime import datetime, timezone

MEMORY_ROOT = Path(__file__).parent.parent

def search(query: str, limit: int = 10) -> list[dict]:
    """
    搜索经验
    1. grep 所有索引文件
    2. 解析匹配行
    3. 按 tier + hit_count 排序
    """
    experiences_dir = MEMORY_ROOT / 'knowledge' / 'experiences'
    results = []
    
    tier_order = {'refined': 0, 'sparse': 1, 'expired': 2}
    
    for tier in ['refined', 'sparse', 'expired']:
        index_file = experiences_dir / tier / '索引.md'
        if not index_file.exists():
            continue
        
        content = index_file.read_text(encoding='utf-8')
        
        # 搜索匹配行
        for line in content.splitlines():
            if query.lower() not in line.lower():
                continue
            
            entry = parse_index_line(line, tier)
            if entry:
                results.append(entry)
    
    # 排序
    results.sort(key=lambda x: (tier_order.get(x['tier'], 3), -x['hit_count']))
    return results[:limit]

def parse_index_line(line: str, tier: str) -> dict:
    """
    解析索引行
    格式: | 日期 | [文件名](路径) | 概要 | hit_count | last_hit_at | reuse_success |
    """
    # 跳过标题行和分隔符
    if line.startswith('|') and ('---' in line or '日期' in line or '文件' in line):
        return None
    
    parts = [p.strip() for p in line.split('|')]
    if len(parts) < 6:
        return None
    
    # 提取文件名（[标题](路径)）
    file_match = re.search(r'\[([^\]]+)\]\(([^)]+)\)', parts[2])
    if not file_match:
        return None
    
    filename = file_match.group(1)
    filepath = file_match.group(2)
    
    try:
        hit_count = int(parts[4]) if parts[4].strip().isdigit() else 0
    except:
        hit_count = 0
    
    return {
        'tier': tier,
        'filename': filename,
        'filepath': filepath,
        'summary': parts[3].strip(),
        'hit_count': hit_count,
        'last_hit': parts[5].strip() if len(parts) > 5 else '',
        'reuse_success': parts[6].strip() if len(parts) > 6 else '',
    }

if __name__ == '__main__':
    query = sys.argv[1] if len(sys.argv) > 1 else ''
    if not query:
        print("Usage: search.py <query>")
        sys.exit(1)
    
    results = search(query)
    for r in results:
        print(f"[{r['tier']}] {r['filename']} (hit: {r['hit_count']}) - {r['summary']}")
```

## 十、与原 v2 方案对比

| 项目 | SQLite/FTS5 方案 | 纯索引方案 |
|------|-----------------|-----------|
| 依赖 | sqlite3, jieba | 无外部依赖 |
| 中文分词 | 需 jieba 预分词 | 直接字符串匹配 |
| 索引损坏风险 | SQLite 可能损坏 | index.md 纯文本，Git 保证 |
| 搜索精度 | BM25 可能不准确 | 精确字符串匹配 |
| 跨环境 | 需重建索引 | clone 即用 |
| 实现复杂度 | 高（SQL + FTS） | 低（grep + 正则） |
| 适合规模 | 万级经验 | 千级经验 |
