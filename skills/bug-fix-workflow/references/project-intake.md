# 项目熟悉

在陌生项目中使用本阶段，目标是快速获得足够上下文，而不是随机翻代码。

## 仓库摸底

1. 检查仓库是否存在 `.codegraph/`。
   - 存在时，架构理解、符号定位、影响范围问题优先使用 CodeGraph。
   - 不存在时，不主动初始化；除非用户明确要求，否则使用 `rg --files`、`rg`、构建文件和 README 类文档。
2. 识别语言、构建系统、测试命令、模块边界和生成代码目录。
3. 确认当前 git 分支、工作区脏文件，以及是否存在用户未提交改动。
4. 查找本地知识来源：
   - 仓库文档
   - LightRAG/GitNexus 索引
   - Confluence 页面
   - 历史 BUG 笔记或复盘记录

## 输出

记录：

- 仓库路径和分支
- 顶层模块地图
- 可用的代码理解工具
- 可能的构建/测试命令
- 尚未确认的假设或缺失权限

## 交接条件

只有在能说清可能代码区域、运行态组件，或明确还需要用户补充什么信息后，才进入 BUG 分析阶段。
